# Correos de Yococino

Plantillas para pegar en Supabase → Authentication → Emails → Templates.

| Plantilla de Supabase | Archivo | Asunto |
|---|---|---|
| Confirm signup | confirmar-cuenta.html | Confirma tu email en Yococino |
| Reset password | recuperar-contrasena.html | Recupera tu contraseña de Yococino |
| Change email address | cambiar-email.html | Confirma tu nuevo email |
| Magic link | enlace-magico.html | Tu enlace para entrar en Yococino |

Remitente propio (SMTP): Authentication → Emails → SMTP Settings, con un servicio de envío (por ejemplo Resend) y el dominio yococino.app verificado.
